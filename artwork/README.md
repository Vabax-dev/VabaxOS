# Artwork

Il logo di VabaxOS, scelto da Vabax. È un marchio: vedi `LICENSES/LicenseRef-VabaxOS-Trademark.txt`.

- `logo-vabaxos.svg`: simbolo e nome, fondo trasparente.
- `logo-vabaxos-symbol.svg`: solo il simbolo, quadrato.
- `logo-vabaxos-symbol-light.svg`: il simbolo per fondi scuri (il blu diventa bianco).

I file sono ricavati dal disegno originale con `scripts/lib/trace-logo.py` (serve `potrace`). Colori: blu notte `#0b1b3f`, viola `#5518ef`, verde menta `#7dd8ad`.

Dove si usano:

- menu di avvio: `image/config/bootloaders/splash.svg`;
- sistema (icona `vabaxos-logo`, sfondo, Impostazioni > Informazioni): pacchetto `vabaxos-branding`.
