# hardware/

Schede di compatibilità hardware, una per macchina provata ([DOC-11](../docs/specs/11_Hardware_Compatibility_Specification.md)).

Livelli: *Supportato*, *Parzialmente supportato*, *Sperimentale*, *Non supportato*, *Richiede firmware*. Nessuna scheda contiene numeri di serie o dati personali.

Per proporre una scheda apri una issue con il modello «Rapporto hardware».
